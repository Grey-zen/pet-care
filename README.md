🐾 Pet Care

Better care for the pets you love.

A modern, premium Pet Care website designed to create a warm, trustworthy, and professional online presence for pet-care businesses, veterinary services, grooming providers, trainers, and animal wellness brands.

The website combines a dark premium aesthetic with fresh green accents, responsive layouts, subtle motion, pet-focused imagery, and clear calls to action.

🛠️ Tech Stack

This project intentionally uses a simple, fast frontend stack:

HTML5 — semantic page structure

CSS3 — responsive layout, animations, gradients, glass effects

Vanilla JavaScript — navigation, scrolling, animations, forms, interactions

Google Fonts / Inter — modern typography

Unsplash — pet photography used throughout the demo

No React, Next.js, Node.js, npm, or package manager is required.

🖼️ Logo & Favicon

The project uses:

pet.png

as both the primary website logo and favicon.

The logo is designed as a circular, glowing Pet Care badge to match the site's green premium aesthetic.

The HTML includes:

<link rel="icon" type="image/png" href="pet.png">
<link rel="apple-touch-icon" href="pet.png">

If you replace pet.png with another logo, keep the same filename to update the branding without changing the HTML.

🚀 Running Locally

Because this is a static website, no npm installation is required.

From the project directory:

python3 -m http.server 8000

Then open:

http://localhost:8000

In GitHub Codespaces, open Ports → 8000 → Open in Browser.

🔧 Customization

Change Brand Name

Edit the Pet Care text inside index.html.

Change Logo

Replace:

pet.png

with your own logo while keeping the same filename.

Change Colors

The primary design variables are located at the top of style.css:

:root {
  --bg: #07110c;
  --panel: #0e1d15;
  --text: #f5f8f5;
  --muted: #a8b4ab;
  --green: #56d363;
  --green-2: #2da84a;
}

Change Contact Information

Update:

Phone number

Email address

Address

Appointment links

inside index.html.

Change Images

Replace the Unsplash image URLs in index.html with your own optimized images.

🔐 Production Notes

This project currently provides frontend UI only.

The following features require a backend or third-party service before production use:

Appointment booking

Newsletter storage

Contact form processing

Emergency support system

Customer accounts

CMS/blog management

The newsletter form currently validates the email address and displays a successful subscription state, but it does not send data to a server.

⚡ Performance

For production deployment:

Convert large images to WebP/AVIF

Use properly sized responsive images

Add loading="lazy" to below-the-fold images

Self-host critical fonts where appropriate

Minify CSS and JavaScript

Configure long-term caching

Add real Open Graph images

Use a CDN for image assets
